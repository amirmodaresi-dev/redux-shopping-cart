# 🛒 Digital Store (Redux Shopping Cart)

A modern, responsive RTL e-commerce application built with **React**, **Redux Toolkit**, and **Bootstrap 5**.

---

## 🚀 Key Features

* **State Management via Redux Toolkit:** Full shopping cart workflow (add items, increase/decrease quantities, remove items, and live total price calculation).
* **RTL & Responsive UI:** Styled with Bootstrap 5 and custom CSS featuring Persian typography (Dana font).
* **Seamless Routing:** Page navigation between Product Showcase and Shopping Cart using React Router DOM v6.
* **Custom Toast Notifications:** Lightweight add-to-cart alert built natively using Bootstrap Toast.

---

## 🛠️ Tech Stack

* **React.js**
* **Redux Toolkit**
* **React Router DOM v6**
* **Bootstrap 5 & Custom CSS3**
